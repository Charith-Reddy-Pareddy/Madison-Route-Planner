# Research evidence and source review

This matrix connects report claims to the project data and the primary sources used to build or measure it.

| Evidence | Source to cite or reproduce | What it supports | Important limit |
| --- | --- | --- | --- |
| Curated Madison places and walking links | [locations.csv](../data/locations.csv), [roads.csv](../data/roads.csv), and their provenance in [data/sources.md](../data/sources.md). The provenance points to the [UW–Madison Campus Map](https://map.wisc.edu/), [City of Madison Parks GIS](https://maps.cityofmadison.com/arcgis/rest/services/Public/OPEN_DATA/MapServer/24), OpenStreetMap, and Nominatim. | The selected places, mapped connections, and distance fields used by the app and the small-graph measurement. | This is a curated set of places and links, not a complete inventory of Madison streets. Coordinates can represent feature centers rather than entrances. |
| Regional walking graph | The dated [Geofabrik Wisconsin OSM extract](https://download.geofabrik.de/north-america/us/wisconsin-261009.osm.pbf), extraction method in [build_osm_graph.py](../benchmarks/build_osm_graph.py), and snapshot checksum and filters in [benchmarks/README.md](../benchmarks/README.md). OpenStreetMap data is under the [Open Database License](https://www.openstreetmap.org/copyright). | The road-network snapshot and filtering choices used to create the nested connected graph prefixes. | OSM tags can be incomplete. The extracted network is a filtered walking graph, not a guarantee that every segment is safe, accessible, or legally walkable. |
| Scale results | [osm-scale-results.csv](../benchmarks/osm-scale-results.csv), generated by [OsmScaleBenchmark.java](../src/OsmScaleBenchmark.java) from the extracted graph. | Build time, search time, edge count, and mean target-route distance at each tested size. | Results use one machine, one Madison-centered seed, and five targets per size. Target distances also grow with graph size, so the results do not isolate graph size as the only cause of slower searches. |
| Curated-graph results | The measurements and reproduction command in [report.md](report.md), using [WalkingRouteBenchmark.java](../src/WalkingRouteBenchmark.java) with the curated CSV files. | Search behavior across ordered pairs in the app's current Madison graph. | These are measurements from the documented machine and run; they should not be generalized to other hardware or treated as a comparison of routing algorithms. |

The official map and data-source pages were checked while preparing this review. For reproducibility, use the dated OSM snapshot and the repository's recorded checksum rather than replacing it with the changing latest extract.
